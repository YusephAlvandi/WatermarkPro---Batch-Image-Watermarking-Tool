Watermark Pro

A professional batch image watermarking tool.

Built with Python, CustomTkinter, and Pillow. Works offline.


WHAT IT DOES

Add customized text watermarks to multiple images simultaneously. You can set all the aspects of the watermark: font, size, color, opacity, rotation, and position. The position can be chosen either by preset or customized coordinates.


COMPETITIVE ADVANTAGE

- Comprehensive control over watermark appearance (font, color, opacity, rotation)
- Batch processing; watermark all the images in a folder with one click
- Preset and desired positioning
- Creates backup of the original images
- Works offline; your images won't leave your local storage
- Built by a physicist who values precision and rigor


HOW TO RUN

pip install customtkinter pillow
python watermark_pro_v2.py
